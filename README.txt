                             AllBinary Platform OpenEuphoria

What is it?

This repository contains code generated by the AllBinary Platform for support in OpenEuphoria.  
This repo is used to allow developers to skip the OpenEuphoria code generation step.

What are some example games with this OpenEuphoria code?

https://allbinary.itch.io (The downloads with "-openeuphoria" in the filename are OpenEuphoria only builds. Currently that only includes nothing. Also the OpenEuphoria builds are not available on Google Play or other stores.)
